# PROMETHEUS-X

AI-Powered Open-Set Industrial Anomaly Detection & Inspection System.

## Frontend
React + Vite + React Router + Framer Motion + Lucide React.

## Run
cd frontend
npm install
npm run dev

This starter contains the animated frontend UI, authentication screens, dashboard, inspection upload screen, and history UI. Supabase authentication, database, storage, and Python/FastAPI AI backend are planned for the next integration phase.
